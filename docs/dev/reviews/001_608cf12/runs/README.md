# Consumer execution evidence

For each case, create an `A-NNN/` directory containing the prompt, brief action journal, final output, read-only Git snapshots, CLI actual records and other relevant evidence. Record significant commands, actual results, scope decisions and commits. Retained journals and outputs are not native complete tool transcripts; only record a native transcript path if an actual native transcript exists.

Update the corresponding record in `../acceptance/cases.json` at every checkpoint. Keep consumer execution separate from `../acceptance/SETUP-SUPPORT.md`. A Passing assessment requires the external oracle and actual case evidence; checker self-tests do not pass a consumer case.
